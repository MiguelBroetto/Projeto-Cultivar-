# Projeto Cultivar 🌱

## Sobre o projeto

O **Projeto Cultivar** é um protótipo de site de comércio eletrônico desenvolvido como parte de um Projeto Integrador. A proposta consiste na criação de uma plataforma virtual para a comercialização de artefatos agrícolas.

O projeto foi desenvolvido com o objetivo de aplicar, na prática, os conhecimentos adquiridos durante o curso, simulando a experiência de compra em uma loja virtual.

## Funcionalidades

- **Catálogo de produtos:** apresentação de artefatos agrícolas.
- **Carrinho de compras:** possibilidade de adicionar produtos ao carrinho.
- **Opções de pagamento:** simulação de pagamento via Pix, cartão de crédito e boleto bancário.
- **Interface de compra:** demonstração das etapas de seleção de produtos e finalização do pedido.
- **Filtros personalizados:** Filtrar por faixa de preço e categoria.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e organização visual da interface.
- **JavaScript:** implementação da lógica e das interações do protótipo.

## Objetivos do projeto

- Aplicar os conhecimentos adquiridos durante o curso.
- Desenvolver um protótipo de comércio eletrônico.
- Praticar conceitos de desenvolvimento front-end.
- Simular o funcionamento de uma loja virtual.
- Integrar os conteúdos estudados em uma atividade acadêmica.

## Observação

Este projeto possui finalidade exclusivamente acadêmica e demonstrativa. Os produtos, as compras e as opções de pagamento fazem parte de um protótipo, não representando necessariamente transações comerciais ou financeiras reais.
